# Chono's icon

Original artwork made for Chono: a PDF page with a copper axe head as a bookmark and a small
"CH". The copper axe recalls the metalwork of the Milagro-Quevedo culture, the Chono people's,
where Guayaquil was founded. Released under the project's license. The CI copies these files
over PdfCraft's `assets/app-icon/` (same file names) before building, so the viewer's program
file, window and taskbar show Chono's icon. The drawing script is `make_icon.py`.
